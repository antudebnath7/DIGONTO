# DIGONTO
### Intelligent Multi-Feature Search & Utility Engine

> "Explore Beyond the Horizon"

## Features
- Keyword Search (Inverted Index)
- Live Weather Report
- Calendar & Date/Time
- Countdown Timer
- Calculator
- Notepad
- Search History & Statistics

## How to Run
g++ -std=c++17 -o digonto main.cpp
./digonto

## OOP Concepts Covered
Classes, Encapsulation, Inheritance (Single/Multiple/Hybrid),
Polymorphism, Templates, File Handling, STL, Exception Handling,
Static Members, Dynamic Memory, and more.
